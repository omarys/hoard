# Cargo Specification

> Generated by openlore v1.2.0 on 2026-10-07 15:46

## Purpose

Manages installation of the hoard CLI application across supported platforms and shell environments.

## Requirements

> `install.sh`

### Requirement: InstallWithCargo

The system SHALL build and install the hoard binary from source using cargo, installing rustup first if cargo is missing.

#### Scenario: CargoAlreadyInstalled
- **GIVEN** A system where cargo is available in PATH
- **WHEN** __hoard_install_with_cargo is executed
- **THEN** hoard is installed from the current directory using cargo install

#### Scenario: CargoMissing
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** A system where neither cargo nor rustup is available
- **WHEN** __hoard_install_with_cargo is executed
- **THEN** rustup is installed from the web and cargo install is invoked

### Requirement: InstallUbuntu

The system SHALL download and install the pre-built deb package matching the project version on ubuntu systems.

#### Scenario: SuccessfulDebInstallation
<!-- openlore-test: tags=smoke (auto) -->
- **GIVEN** An Ubuntu system with network access and a released deb package for the current version
- **WHEN** __hoard_install_ubuntu is executed
- **THEN** The deb package is fetched to /tmp, installed via dpkg, and cleaned up

#### Scenario: DebPackageNotFound
<!-- openlore-test: tags=regression (auto) -->
- **GIVEN** No release package exists on GitHub for the current version
- **WHEN** __hoard_install_ubuntu is executed
- **THEN** An error message is displayed directing the user to install from source

### Requirement: InstallMac

The system SHALL display installation and shell plugin instructions for macos users via homebrew or source.

#### Scenario: DisplayMacOSInstructions
- **GIVEN** A macOS system
- **WHEN** __hoard_install_mac is executed
- **THEN** Brew installation instructions and shell configuration hints are printed to stdout

### Requirement: DetectAndInstallOs

The system SHALL detect the operating system and route execution to the appropriate platform installation routine.

#### Scenario: LinuxOSDetection
- **GIVEN** An OSTYPE starting with linux
- **WHEN** __hoard_detect_os is executed
- **THEN** __hoard_install_ubuntu is called

#### Scenario: MacOSDetection
- **GIVEN** An OSTYPE starting with darwin
- **WHEN** __hoard_detect_os is executed
- **THEN** __hoard_install_mac is called
