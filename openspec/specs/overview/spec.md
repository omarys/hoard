## Purpose

OpenSpec (Hoard) is a CLI and terminal user interface tool designed for organizing, searching,
parameterizing, and executing shell command snippets across collections known as troves. It enables
developers to curate reusable command snippets, safely redact sensitive tokens, interactively
substitute arguments, and generate shell commands using natural language via OpenAI.

## Requirements

### Requirement: SystemCapabilities

The system SHALL provide the following capabilities:
- Use SQLite as the primary persistence layer with automated migrations and backward compatibility for legacy YAML troves
- Implement dual user interfaces consisting of a headless CLI for scripting/fast access and an interactive TUI for search, inspection, and parameterization
- Enforce proactive client-side secret redaction to prevent accidental persistence of credentials in saved commands
- Integrate OpenAI Chat API directly within the terminal UI workflow to convert natural language queries into executable shell commands
- Decouple interactive parameter input from command definition, allowing reusable parameterized command templates with dynamic token replacement

## Technical Notes

- **Architecture Style**: Layered architecture: Presentation (CLI argument parsing, shell integration, and interactive terminal UI) → Application/Domain (command lifecycle, parameterization, filtering, and secret redaction) → Persistence and External Services (SQLite storage and OpenAI API integration).
- **Security Model**: Local single-user trust model with no multi-user authentication or role-based access control. Security focuses on credential leakage prevention via SecretRedactionService, which scans commands for passwords, tokens, and API keys to replace them with parameter placeholders prior to storage. OpenAI API key presence is verified via KeyNotSetControls for AI features, though whether the key is loaded from an environment variable or local configuration file is uncertain from the provided analysis.
- **External Integrations**: SQLite (embedded local relational database for trove and command storage), OpenAI Chat API (external cloud service for natural language command generation), Host Shell Environments (Bash, Zsh, and Fish integration via ShellService), Crates.io and GitHub Releases (package distribution and CI/CD workflows)
